# 声音与配音（音频模块）

> 何时读：需要配音/旁白/BGM/音效设计，或成片声音不合意时。设计阶段就规划，别等成片再补。

## 一、声音四轨设计（在分镜阶段一并规划）

每个镜头在设计时就标注四条声音轨的去向：

| 轨 | 内容 | 由谁做 |
|---|---|---|
| 对白/旁白 | 台词、旁白 | 视频模型原生音频 或 后期 TTS（见下） |
| 环境声 | 雨、风、街道、室内底噪 | 模型原生 或 后期音效库 |
| 动作音效 | 脚步、门、刀风、碰撞 | 模型原生 或 后期音效库 |
| 音乐 | BGM、情绪推进 | 后期为主（模型生成的音乐可控性低） |

分镜表「声音设计」栏就是这条设计的载体——按声音符号（（ ）音乐 / < >音效 / { }台词 / 【 】字幕）并入视频提示词末尾。

## 二、原生音频 vs 后期配音（决策）

| 场景 | 选择 | 理由 |
|---|---|---|
| 简单对白、氛围音，语气要求不高 | 模型原生音频（提示词用符号写） | 一条生成省事，口型自然 |
| 多角色对话、音色要跨集一致 | **后期 TTS** | 音色可控、可改稿、跨集稳定 |
| 旁白解说型（漫画解说/剧情旁白） | **后期 TTS** | 旁白必须字字清晰、语速可控 |
| 重要台词（剧情关键句） | 后期 TTS 或换镜重生成 | 模型发音出错时无法单独修 |

原则：**模型原生音频管氛围，后期 TTS 管台词与叙事**。两者可混用——视频生成时静音或保留环境音，台词轨后期贴上。

## 四、台词标注与拆句（对接 TTS）

把剧本改成配音稿，三拆分原则：

1. **叙事描写**（环境/动作/心理旁观）→ 全部归【旁白】单独一段
2. **人物内心想法** → 【角色名】单独一段（标注内心放缓）
3. **人物对话**（「XX道："……"」）→ 拆两段：动作归【旁白】，纯台词归【角色名】

带参数标注格式（对接批量生成）：
```
【角色名｜VoiceID｜rate=±X%｜style=xxx】
纯台词，用 / 做断句分隔/
```

**断句与停顿**（朗读不卡顿的关键）：

| 符号 | 场景 | 停顿 |
|---|---|---|
| ， | 句内短换气 | 0.25s |
| 。！？ | 单句结束 | 0.6s |
| ： | 人物切换/转场 | 1.0s |
| 空行 | 大段落切换 | 1.5s |
| 诗词 | 每句单独换行 | 按句断 |

**避错五条**：
1. 一段文本只能有一个角色标签，禁止混多角色台词
2. 动作/神态/环境描写绝不混入角色对话段
3. 同一角色全书固定音色、语速，不随意换
4. 情绪统一用 style 标注（angry/fearful/cheerful）
5. 内心独白单独一段，不与外部对话合并

## 五、Edge TTS 落地（免费本地方案）

```bash
# 单段生成（rate/pitch 按音色表）
edge-tts --voice zh-CN-XiaoxiaoNeural --rate=+0% --pitch=+0Hz --text "文本" --write-media out.mp3

# 列出全部可用音色（查中文音色）
edge-tts --list-voices | grep zh-CN
```

批量与进阶（多角色自动分轨、按标注自动参数、字幕对齐）可参考开源项目 novel2voice 的脚本链（generate_audiobook.py，支持 【角色】 标签自动识别）。
本机如需音频拼接与响度标准化，用 ffmpeg（本机已有）：拼接 `ffmpeg -f concat -i list.txt -c copy out.mp3`；响度达标 `ffmpeg -i in.mp3 -af loudnorm=I=-16:TP=-1.5:LRA=11 out.mp3`（单遍 loudnorm 打不到目标，实测可偏离 3.7dB——重要交付跑两遍）。

## 六、BGM 与音效

- **选曲按情绪关键词**：紧张/温馨/悬疑/史诗/治愈/欢快——先匹配段落情绪，再挑具体曲。
- **卡点**：高能段落（⚡PEAK、打脸/反转）让画面切换对齐音乐重拍；做法是先生成/选定音乐，再把镜头时长往拍点上靠（秒级时间粒度的合理使用场景，见 `prompt-craft.md`）。
- **混音**：台词轨优先，BGM 在台词段自动压低（ducking）；环境音做底、音效做点。
- **转场配合**：声音先行（JC）与声音顿帧是免费又好用的转场强化——转场前零点几秒先给下一场的声音。

## 七、合流与发布前检查

1. 视频轨（逐镜拼接，跳帧修复见 SKILL.md 排障表）→ 2. 台词/旁白轨贴时间轴 → 3. BGM/音效轨 → 4. 响度标准化（两遍 loudnorm）→ 5. 字幕轨（字幕文字只能来自定稿剧本，不得用转写结果——转写会把台词听错）。
发布前逐项：口型与台词对齐、接缝处音频连续、字幕与话音同步、整体响度一致、无杂音爆音。
